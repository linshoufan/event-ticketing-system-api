==============================
共用規範
==============================

【 Base URL 】
https://api.your-domain.com/v1

【 角色定義 】
welfare_member  福委會
employee        一般員工
hr              HR

【 Request Headers 】
所有 API 都要帶

Authorization: Bearer <jwt_token>
Content-Type: application/json

【 統一 Response 格式 】

成功：
{
  "data": { ... }
}

分頁列表：
{
  "data": [ ... ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 100
  }
}

錯誤：
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable message"
  }
}

【 HTTP Status Code 】
200  成功
201  建立成功
207  批量操作部分成功
400  格式錯誤 / 參數不合法
401  未登入
403  權限不足
404  資源不存在
409  業務邏輯衝突（超賣、重複報名...）
500  系統錯誤




==============================
Auth（公司員工資料庫登入）
==============================


【 登入流程 】

1. 前端顯示四個按鈕：第一次登入 / 員工登入 / 福委登入 / HR 登入
2. 點擊後輸入員工編號和密碼
3. 打 POST /auth/login，帶 employeeId、password、role（第一次登入 role 帶 null）
4. Account Service 去外部員工 DB 驗證身份
5. 驗過後查自己的 DB，如果有帶 role 就確認是否吻合
6. 第一次登入就建立 user，role 預設 employee
7. 發 JWT 回去，之後每次打 API 都帶在 Header


------------------------------

【 POST /auth/login 】
登入
Roles: 不需要 token

Request Body
{
  "employeeId": "1123213",
  "password": "employee",
  "role": "welfare_member"    // 第一次登入帶 null
}

Response 200
{
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "role": "welfare_member"
  }

{
  "error": { "code": "EMPLOYEE_NOT_FOUND", "message": "Employee not found" }
}

Response 401
{
  "error": { "code": "INVALID_CREDENTIALS", "message": "Invalid password" }
}

Response 403
{
  "error": { "code": "INVALID_ROLE", "message": "Role does not match" }
}

==============================
Ticket Service（票券管理）
==============================

【 GET /tickets 】
取得自己的票券列表
Roles: employee、welfare_member、hr

Query Params
?status=unused
status 可選值：used | unused | invalid

status filter 依 DB 票券狀態查詢：
unused    尚未報到 / 尚未核銷
used      已報到 / 已核銷
invalid   已作廢票券

Response 中的 status 可能是顯示用狀態：
- 若 DB status = unused，但目前不在活動時間內，response status 會顯示為 invalid，checkinAvailable=false。
- 這個顯示用 invalid 不會寫回 DB，DB 仍是 unused。


Response 200
{
  "data": [
    {
      "ticketId": "tk_001",
      "eventId": "ev_001",
      "eventName": "夏日烤肉趴",
      "eventStartTime": "2025-07-15T18:00:00Z",
      "eventLocation": "台北辦公室頂樓",
      "status": "unused",
      "checkinAvailable": true
    }
  ]
}

【 POST /tickets/{ticketId}/checkin 】
報到 / 核銷
Roles: employee、welfare_member、hr

- employee、hr：後端驗證本人、活動時間與地理位置
- welfare_member：福委核銷，略過本人、活動時間與地理位置檢查
- DB status = unused：成功後改為 used。
- DB status = used：employee、hr 回 TICKET_INVALID；welfare_member 重複核銷仍回 200。
- DB status = invalid：所有角色皆回 TICKET_INVALID。

Request Body
employee、hr 必填；welfare_member 可不帶，若有帶也會被忽略。
{
  "latitude": 25.0479,
  "longitude": 121.5320
}

Response 200
{
  "data": {
    "checkedIn": true,
    "checkedInAt": "2025-07-15T18:05:00Z"
  }
}

福委重複核銷仍回 200，回傳原本報到時間：
{
  "data": {
    "checkedIn": true,
    "checkedInAt": "2025-07-15T18:05:00Z"
  }
}
invalid 票券仍回 TICKET_INVALID。

Response 400
{ "error": { "code": "OUT_OF_RANGE", "message": "User is not within event location" } }
{ "error": { "code": "TICKET_INVALID", "message": "Ticket is used or invalid" } }
{ "error": { "code": "TICKET_INVALID", "message": "Ticket is invalid" } }
{ "error": { "code": "NOT_EVENT_TIME", "message": "Check-in only available during event time" } }
