==============================
共用規範
==============================

【 Base URL 】
https://api.your-domain.com/v1

【 角色定義 】
welfare_member  福委會
employee        一般員工
hr              HR

【 Request Headers 】
所有 API 都要帶

Authorization: Bearer <jwt_token>
Content-Type: application/json

【 統一 Response 格式 】

成功：
{
  "data": { ... }
}

分頁列表：
{
  "data": [ ... ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 100
  }
}

錯誤：
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable message"
  }
}

【 HTTP Status Code 】
200  成功
201  建立成功
207  批量操作部分成功
400  格式錯誤 / 參數不合法
401  未登入
403  權限不足
404  資源不存在
409  業務邏輯衝突（超賣、重複報名...）
500  系統錯誤




==============================
Auth（第三方登入）
==============================


【 登入流程 】

1. 前端顯示「使用 Google 帳號登入」按鈕
2. 使用者點擊後，導向 Google 登入頁面
3. 使用者完成登入，Google 將使用者導回 callback URL
4. 前端從 callback URL 取得 jwt_token
5. 將 jwt_token 存起來，之後每次打 API 都帶在 Header

【 GET /auth/login 】
取得 Google 登入的導向網址
Roles: 不需要 token

Response 200
{
  "data": {
    "loginUrl": "https://accounts.google.com/o/oauth2/v2/auth?..."
  }
}


------------------------------

【 GET /auth/callback 】
第三方登入完成後的 callback，由前端接收 token
Roles: 不需要 token

Query Params
?code=xxxxx（第三方回傳的授權碼，由後端換成 jwt_token）

Response 200
{
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "role": "employee"
  }
}


------------------------------

【 POST /auth/logout 】
登出，讓 token 失效
Roles: all roles

Response 200
{
  "data": { "loggedOut": true }
}

------------------------------

【 GET /me 】
取得當前登入使用者資訊
Roles: all roles

Response 200
{
  "data": {
    "userId": "u_abc123",
    "username": "john.doe",
    "role": "employee",
    "preferences": ["outdoor", "food"],
    "registrationStatus": "active",
    "unlockAt": null,
    "autofill": {
      "dietType": "non-veg",
      "selfDriving": true
    }
  }
}

registrationStatus 可選值
active   可以報名
locked   被鎖定，無法報名（unlockAt 為解鎖時間）

==============================
Transaction Service（報名管理）
==============================

【 GET /events/{eventId}/eligibility 】
檢查當前使用者報名資格
Roles: employee

Response 200（符合資格）
{
  "data": {
    "eligible": true,
    "reason": null,
    "remainingTickets": 12,
    "isWaitlist": false
  }
}

Response 200（不符合資格）
{
  "data": {
    "eligible": false,
    "reason": "LOCKED",
    "remainingTickets": 12,
    "isWaitlist": false,
    "unlockAt": "2025-06-18T00:00:00Z"
  }
}

reason 可選值
LOCKED              帳號被鎖定，unlockAt 為解鎖時間
NO_TICKETS          無剩餘名額（可候補）
ALREADY_REGISTERED  已報名

------------------------------

【 GET /transactions 】
查詢自己的報名紀錄
Roles: employee

Query Params
?page=1&limit=10&status=confirmed
status 可選值：confirmed | waitlist | cancelled

Response 200
{
  "data": [
    {
      "transactionId": "tx_001",
      "eventId": "ev_001",
      "eventName": "夏日烤肉趴",
      "eventStartTime": "2025-07-15T18:00:00Z",
      "status": "confirmed",
      "waitlistNumber": null,
      "guestCount": 2,
      "dietType": "non-veg",
      "selfDriving": true,
      "registeredAt": "2025-05-18T09:00:00Z",
      "ticketId": "tk_001"
    }
  ],
  "pagination": { "page": 1, "limit": 10, "total": 5 }
}

------------------------------

【 POST /transactions 】
提交報名
Roles: employee

規則：ticketLimit 有設定（限名額）→ 只限員工本人，guestCount 固定為 0
      ticketLimit 為 null（不限名額）→ 可填家屬人數，guestCount >= 0

Request Body
{
  "eventId": "ev_001",
  "guestCount": 2,
  "dietType": "non-veg",
  "selfDriving": true,
  "saveAutofill": true
}

dietType 可選值：veg | non-veg | none

Response 201（報名成功）
{
  "data": {
    "transactionId": "tx_001",
    "status": "confirmed",
    "ticketId": "tk_001",
    "registeredAt": "2025-05-18T09:00:00Z"
  }
}

Response 201（候補）
{
  "data": {
    "transactionId": "tx_002",
    "status": "waitlist",
    "waitlistNumber": 3,
    "ticketId": null,
    "registeredAt": "2025-05-18T09:00:00Z"
  }
}

Response 409（帳號鎖定）
{
  "error": {
    "code": "ACCOUNT_LOCKED",
    "message": "Account is locked",
    "unlockAt": "2025-06-18T00:00:00Z"
  }
}

Response 409（其他）
{
  "error": { "code": "ALREADY_REGISTERED", "message": "Already registered for this event" }
}

------------------------------

【 PATCH /transactions/{transactionId} 】
修改報名細節（不影響報名順序與資格）
Roles: employee
可修改欄位：dietType、selfDriving、guestCount（僅限不限名額的活動）

Request Body
{
  "guestCount": 3,
  "dietType": "veg",
  "selfDriving": false
}

Response 200
{
  "data": { "updated": true, "updatedAt": "2025-05-18T10:30:00Z" }
}

Response 409
{
  "error": { "code": "PAST_CANCELLATION_DEADLINE", "message": "Modification deadline has passed" }
}

------------------------------

【 DELETE /transactions/{transactionId} 】
取消報名
Roles: employee

Response 200
{
  "data": { "cancelled": true }
}

Response 409
{
  "error": { "code": "PAST_CANCELLATION_DEADLINE", "message": "Cancellation deadline has passed" }
}

==============================
Ticket Service（票券管理）
==============================

【 GET /tickets 】
取得自己的票券列表
Roles: employee

Query Params
?status=unused
status 可選值：used | unused | invalid

invalid   非活動期間（報名後尚未到活動時段，或活動已結束）
used      活動期間且票券已兌換（報到完成）
unused    活動期間且票券尚未兌換（可報到）


Response 200
{
  "data": [
    {
      "ticketId": "tk_001",
      "eventId": "ev_001",
      "eventName": "夏日烤肉趴",
      "eventStartTime": "2025-07-15T18:00:00Z",
      "eventLocation": "台北辦公室頂樓",
      "status": "unused",
      "checkinAvailable": true
    }
  ]
}

------------------------------

Roles: employee、welfare_member

Response 200

------------------------------

【 POST /tickets/{ticketId}/checkin 】

==============================
Notification
==============================

【 GET /notifications 】
取得使用者通知列表
Roles: all roles

Query Params
?page=1&limit=20&read=false

Response 200
{
  "data": [
    {
      "notificationId": "nf_001",
      "type": "REGISTRATION_SUCCESS",
      "title": "報名成功",
      "message": "您已成功報名「夏日烤肉趴」",
      "eventId": "ev_001",
      "read": false,
      "createdAt": "2025-05-18T09:01:00Z"
    }
  ],
  "pagination": { "page": 1, "limit": 20, "total": 10 }
}

type 可選值
REGISTRATION_SUCCESS  報名成功
WAITLIST_PROMOTED     候補升為正取
EVENT_REMINDER        活動提醒
ACCOUNT_LOCKED        帳號被鎖定通知
ACCOUNT_UNLOCKED      帳號解鎖通知
